## Design note

The v0.4 builder extends the retained v0.3 entity graph additively. Every new
manifest unit receives a locale-neutral unit identity plus separate English
source and Indonesian translation expressions, source bindings, rights
bindings, and QA provenance. The manifest artifact points to the canonical
lane path `translation/TRANSLATION_MANIFEST.jsonl`, so replay bytes do not
depend on the chosen output-directory name. Reader-facing TeX remains the
content authority; the backend is a deterministic, language-portable index and
not a replacement for the edition.
