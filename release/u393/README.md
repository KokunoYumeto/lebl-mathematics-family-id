# Overlay pembaca U393

Direktori ini mengikat pembaca R006 Jilid II pada prefiks terjemahan sampai
akhir Bagian 11.7. `ch-approximate.tex` berhenti sebelum pembukaan Bagian 11.8;
`realanal2.tex` adalah driver Indonesia; dan `build_u393.ps1` memverifikasi
hash sumber, batas semantik, converter, indeks, glosarium, serta stabilitas
produk bantu antarpas.

Hasil acuan adalah PDF 224 halaman, 2.281.400 byte, SHA-256
`5a8db6dd8f9b559c578fe31678943e093650019686e2e75cc752d1b2b49bb211`.
