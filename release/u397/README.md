# Overlay pembaca U397

Direktori ini mengikat pembaca R006 Jilid II pada prefiks terjemahan sampai
akhir Subbagian 11.8.1, `Polinom trigonometri`. `ch-approximate.tex` berhenti
sebelum pembukaan Subbagian `Fourier series`; `realanal2.tex` adalah driver
Indonesia; dan `build_u397.ps1` memverifikasi hash sumber, batas semantik,
converter, indeks, glosarium, serta stabilitas produk bantu antarpas.

Bangun Jilid I lebih dahulu agar `realanal.aux` tersedia untuk rujukan
antarjilid. Hasil acuan adalah PDF 226 halaman, 2.292.242 byte, SHA-256
`40b2e2cb27dd59d288ef76453ae293558fcd1ae8efb96e1e87a646f8f0b8f73d`.
