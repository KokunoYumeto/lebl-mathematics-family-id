# Overlay pembaca U370

Direktori ini mengikat pembaca R006 Jilid II pada prefiks terjemahan sampai
akhir Bagian 11.6. `ch-approximate.tex` berhenti sebelum pembukaan Bagian 11.7;
`realanal2.tex` adalah driver Indonesia; dan `build_u370.ps1` memverifikasi
hash sumber, batas semantik, converter, indeks, glosarium, serta stabilitas
produk bantu antarpas.

Hasil acuan adalah PDF 208 halaman, 2.161.063 byte, SHA-256
`00fde02788a34292a44f38fed3146df2dbb4db8d942672e59fd54c9e362b51b7`.
